# Contributing

Report reproducible problems through [GitHub Issues](https://github.com/Bosaiting/dsh-composer-predictions/issues).

Include plugin version, DSH version, Desktop/Web, operating system, relevant theme/completion plugins and a minimal reproduction. Use synthetic conversations. Remove credentials, account identifiers, private paths and conversation content from logs and screenshots.

Follow [development instructions](docs/DEVELOPMENT.md). Routine tests use mocked model transport and do not make paid calls. Add a focused regression for behavior changes. Preserve undoable insertion, cancellation, stale-response guards, bounded work and cleanup when disabled, hidden or unmounted.

Read [known issues](docs/KNOWN_ISSUES.md). For sensitive reports, use a private channel already provided by the release maintainer; do not post credentials or exploit details publicly. No dedicated security contact has been assigned yet.
