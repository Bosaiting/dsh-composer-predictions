# 0.4.3 修复验证

日期：2026-10-26。状态：本地修复候选包，未外部发布。

## 修复前后对照

使用原 0.4.2 客户端和修复后的实际组件重放相同的模拟场景：

| 场景 | 修复前 | 0.4.3 |
| --- | --- | --- |
| 原生组合输入标记已设置，同任务派发 Tab | 提前接管 | 不接管、不插入 |
| compositionend 后不足 10ms 的 Tab | 提前接管 | 保留保护，结束后可正常接受 |
| 组合输入覆盖初始化补取，随后取消输入 | 0 次请求，未恢复 | 输入期间 0 次，结束后 1 次，后续不重复 |
| 无关 completion/help 插槽 | 建议被隐藏 | 建议保持可用 |
| 明确 priority=50 的 peer 同时注册 ghost 插槽 | 仍被插槽名称压制 | 尊重明确优先级；合并通知时不误取消在途请求 |
| 其他编辑器的输入法和 Tab | 干扰本编辑器建议 | 不接管其他编辑器，保留本编辑器建议 |
| Host 配置 60 秒 | 25 秒被取消 | 30 秒和 64 秒仍可继续，65 秒安全截止 |
| Host 配置 1 秒但正文一直不返回 | 仍等固定 25 秒 | 6 秒安全截止（1 秒预算加 5 秒余量） |

额外检查了失败后不会因组合输入自动循环重试、原始建议的缓存与拒绝状态、请求取消、超时状态及晚到结果拒绝。
